수신 데이터 설정

지원 데이터 형식

CSV: 한 줄마다 센서값을 출력합니다. 숫자가 아닌 첫 행은 헤더로 인식합니다.

temperature,light
24.3,120
24.5,125

JSON: 한 줄에 JSON 객체 하나를 출력합니다. 숫자 필드만 그래프에 표시합니다.

{"temperature":24.3,"light":120}
시간축은 브라우저 수신 시각 기준입니다. CSV 따옴표와 중첩 JSON, 바이너리 프로토콜은 이 버전에서 지원하지 않습니다.

HEX 파일 · 트랙 B

파일 선택 후 수동 플래싱 안내가 표시됩니다.

MICROBIT 드라이브에 복사하는 방법
  1. 데이터 전송을 지원하는 USB 케이블로 micro:bit를 연결하세요.
  2. 연결 중이라면 위의 해제 버튼으로 시리얼 연결을 종료하세요.
  3. HEX 파일의 다운로드 버튼을 누르세요.
  4. 파일 탐색기 / Finder에서 MICROBIT 드라이브를 여세요.
  5. 다운로드한 .hex 파일을 드라이브로 복사하세요.
  6. LED 점멸과 재부팅이 끝날 때까지 케이블을 분리하지 마세요.
  7. 이전 장치 재연결을 누르세요. 필요하면 장치를 다시 선택하세요.

이 앱은 수동 복사의 완료 여부를 자동 확인할 수 없습니다. 드라이브에 FAIL.TXT가 생기면 해당 파일의 오류 내용을 확인하세요.

Web USB 직접 플래싱 안내

이 버전은 트랙 A 전송을 구현하지 않았습니다. 직접 플래싱에는 지원되는 DAPLink/CMSIS-DAP 프로토콜과 micro:bit 버전별 검증이 필요합니다. HEX를 임의 USB 엔드포인트에 전송하지 않습니다.
