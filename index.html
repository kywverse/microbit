연결 대기

1. 장치 연결

전용 HEX를 설치한 micro:bit V2를 연결하세요.

MakeCode, 다른 시리얼 모니터 등이 포트를 사용 중이면 먼저 연결을 해제하세요.

2. 수집 센서 선택

연결 후 선택한 설정을 자동으로 전송합니다.

센서 사용 시 주의사항
  • 센서 조합이 바뀌면 기존 데이터가 초기화됩니다. 먼저 내보내세요.
  • 선택 해제 후 적용하면 수집을 중지합니다.
  • 온도는 칩 온도 기반 근사값입니다.
  • 소리 크기는 0~255 수준값이며 dB가 아닙니다.
  • 밝기는 LED 매트릭스로 측정합니다.
  • 나침반은 보정 완료 후 값이 표시됩니다.
  • 핀 터치는 해당 핀과 GND를 함께 만지는 기본 저항식 입력입니다.
  • 핀에 외부 회로가 연결되어 있다면 터치 측정과 충돌할 수 있습니다.

3. HEX 설치 · 트랙 B

파일 검사 → 다운로드 → MICROBIT 드라이브에 복사

수동 플래싱 방법
  1. 데이터 전송이 가능한 USB 케이블로 연결합니다.
  2. 웹앱이 연결 중이면 먼저 해제를 누릅니다.
  3. 아래 목록의 HEX 다운로드를 누릅니다.
  4. 파일 탐색기 / Finder에서 MICROBIT 드라이브를 엽니다.
  5. 다운로드한 HEX 파일을 드라이브에 복사합니다.
  6. LED 점멸과 재부팅이 끝날 때까지 기다립니다.
  7. 웹앱에서 다시 연결합니다.
브라우저는 복사 완료 여부를 자동 확인할 수 없습니다. FAIL.TXT가 생기면 내용을 확인하세요.
직접 USB 플래싱 안내

이 버전은 Web USB 직접 플래싱을 구현하지 않습니다. 검증되지 않은 USB 전송 대신 수동 복사 경로를 사용합니다.
