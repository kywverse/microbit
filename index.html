1. 시뮬레이션 모드 사용: 아래 버튼을 눌러 센서 데이터 수신 및 차트/경보 기능을 즉시 동작시켜 볼 수 있습니다.

2. 실제 마이크로비트 연결: 웹앱을 독립된 새 브라우저 탭(Chrome/Edge)에서 직접 열어 사용해주세요.

MakeCode 코드 및 연결 가이드

micro:bit v2에 다운로드할 파이썬 또는 자바스크립트 코드입니다.

1. MakeCode 에디터에 접속하여 새 프로젝트를 생성합니다.

2. 아래 코드 블록 중 하나를 복사하여 에디터에 붙여넣고 micro:bit v2에 다운로드하세요.

def on_forever():
    t = input.temperature()
    l = input.light_level()
    s = input.sound_level()
    # 파싱 규격 포맷 (Key-Value): T:온도,L:광도,S:음량
    serial.write_string("T:" + str(t) + ",L:" + str(l) + ",S:" + str(s) + "\n")
    basic.pause(500)

basic.forever(on_forever)
basic.forever(function () {
    let t = input.temperature()
    let l = input.lightLevel()
    let s = input.soundLevel()
    // 파싱 규격 포맷: T:온도,L:광도,S:음량
    serial.writeString("T:" + t + ",L:" + l + ",S:" + s + "\n")
    basic.pause(500)
})
지원되는 다양한 시리얼 전송 포맷:
• Key-Value: T:25,L:150,S:60
• JSON: {"temp":25, "light":150, "sound":60}
• CSV: 25, 150, 60 (온도, 광도, 음량 순)
